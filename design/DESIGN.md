# XT Work Studio — 交互设计说明

## 产品视角

面向需要同时处理编码、调研和内部资料查询的研发与产品人员。页面的唯一核心任务是：让用户知道任务做到哪里、由谁执行、现在是否需要自己介入，以及最后产生了什么。

## 信息架构

- 左栏：采用 Codex 项目列表式层级；“任务”是模块标题，“进行中 / 待确认”是可折叠分组，具体任务缩进显示，历史记录单列为“最近任务”。
- 当前任务使用由 Relay Violet 过渡到 Evidence Aqua 的低对比度横向渐变，不再使用模板化的单色卡片和左侧色条。
- 知识库拥有独立路由，以知识集合组织文档、仓库和业务数据，并显式展示同步、权限和任务引用规则。
- 插件拥有独立路由，以“能力包”呈现可启停的 MCP、应用连接器与配套技能；支持搜索及启用状态筛选。
- 技能拥有独立路由，沿用 Nezha 的来源、依赖和 `SKILL.md` 模型，展示工作区 / 个人 / 系统来源，并支持预览与直接带入新任务。
- 中栏：任务目标、执行轨道、步骤证据、实时终端与补充输入。
- 右栏：资源、约束和交付包。资源支持多个仓库、文档与数据源；交付包支持多仓库变更集。
- 底部输入框属于当前任务，同时承载执行后端、连接状态、模型与权限配置。
- 设置从左下角用户菜单进入，采用分组双栏结构，覆盖通用、外观、本地 Codex app-server、公司 API 和版本信息；密钥仅显示掩码，不在界面回显明文。

## 视觉方向

参考 Codex 的深色低噪声界面、细线分隔、紧凑信息密度和悬浮输入框，但不直接复刻。

设计签名是“执行轨道”：一条纵向状态线把公司 API 的资料分析与本地 Codex 的代码执行连接成同一个任务过程，用户不用理解底层切换。

### 色彩

- Obsidian `#0B0C0E`：主背景
- Slate `#141619`：基础表面
- Alloy `#282C32`：边界
- Paper `#F1F3F5`：主文字
- Relay Violet `#8290FF`：本地执行状态
- Evidence Aqua `#62D8C6`：数据证据与完成状态
- Approval Amber `#E6B85F`：需要人工介入

### 字体

- 正文及标题：系统 UI 字体，macOS 优先 SF Pro，中文优先苹方。
- 日志及路径：SF Mono / Consolas。
